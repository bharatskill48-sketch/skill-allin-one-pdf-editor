
# SKILL ALL IN ONE PDF EDITOR

### Advanced All-in-One Document Workspace

A modern browser-based document editor designed to manage multiple file formats in one place.

## Features

- PDF Viewer
- PDF Text Annotation
- PDF Drawing Annotation
- PDF Export
- Image Viewer
- Image Rotate
- PNG Export
- DOCX Preview
- XLSX / XLS Preview
- CSV Preview
- TXT Reader
- Responsive Mobile Design
- Dark Mode and Light Mode
- Local Browser File Processing

## Supported File Formats

| Format | Support |
|---|---|
| PDF | View, annotate, export |
| PNG | Preview, rotate, export |
| JPG / JPEG | Preview, rotate, export |
| WEBP | Preview, rotate, export |
| DOCX | Text preview |
| XLSX / XLS | Spreadsheet preview |
| CSV | Spreadsheet preview |
| TXT | Read text |
| DWG / DXF | CAD engine integration required |

## Technology

- HTML5
- CSS3
- JavaScript
- Vite
- PDF.js
- PDF-lib
- Mammoth.js
- SheetJS

## Run Locally

Install Node.js 20 or newer.

Run:

npm install

Then:

npm run dev

Build the production app:

npm run build

## Important Notes

This is an initial working starter version.

Advanced PDF editing, OCR, digital signatures, form filling, DWG editing and cloud storage require additional development and integrations.

DWG support requires a dedicated CAD SDK or backend service.

## Privacy

Files are processed locally in the browser in this starter version.
